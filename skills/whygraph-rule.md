
## whygraph

This repo has a why graph. Before you change a symbol, run
`whygraph carry <file>:<symbol>`; when a decision changes, run
`whygraph impact <id>`; when you wonder why code is the way it is, run
`whygraph why <file>:<symbol>`. `carry` also shows the decisions and checks
on the symbols it uses and on those that use it; a decision there binds your
edit too. The whygraph skill says how to read the answers.
